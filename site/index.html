Caddy で配る、小さな見本
トップ Caddy の機能 /healthz

このサイトは、インフラエンジニア向けのハンズオン見本です。静的なページを Caddy で配り、手元では Docker Compose、公開先では Render の無料 Web サービス（コンテナ 1 つ）として動かします。

  • 手元 Compose で Web と、逆プロキシ先の小さな API を起動します。ブラウザは http://localhost:8080/ です。
  • 公開 Render では TLS が入口で終わります。Caddy は環境変数 PORT の平文 HTTP だけを待ちます。
  • 確認 /healthz は常に 200 を返します。デプロイのヘルスチェックと、手元の確認スクリプトがここを見ます。

この見本で触るもの

  • 日本語コメント付きの Caddyfile（圧縮、セキュリティヘッダ、キャッシュ、JSON のアクセスログ）
  • arm64 と amd64 のどちらでも動く、公式イメージをタグ固定した Dockerfile
  • 手元だけで有効な /api/* の逆プロキシ
  • 無料プランの Web サービスを定義した render.yaml
